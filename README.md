# 谜语书信 · 见字如面

一个使用合成数据的四角色互动 Demo。源码采用 React、TypeScript、Vite、React Router、Tailwind、React Hook Form、Zod 与 Dexie；通过 Sites 私有部署。

## 本地运行

需要 Node.js 24 与 npm。首次运行 `npm ci`，之后运行 `npm run dev` 并打开终端显示的本地地址。

- `npm run build`：类型检查与生产构建。
- `npm test`：业务规则单元测试。
- `npm run e2e`：桌面与手机完整操作测试。首次使用需安装 Playwright Chromium：`npx playwright install chromium --only-shell`。

## 体验方式

首页点击“进入演示”。在右上方“演示设置”切换角色与具体身份。

| 角色 | 推荐身份 | 体验重点 |
| --- | --- | --- |
| 小朋友 | 小禾 | 阅读线上来信、猜谜、保存回信并提交审核 |
| 志愿者 | 林语 | 新写一封信、保存草稿、按退回建议修改 |
| 老师 | 周老师 | 纸质打印、实际交付、代录或上传合成回信 |
| 运营 | 小满 | 审核两个方向的信件、结对、暂停恢复与跟进 |

芽芽与苏宁为待结对身份。纸质场景属于阿川、许舟、周老师。可在演示设置向前调整日期，观察逾期待办；重置后恢复到2026年10月19日。

## 数据边界

数据仅保存于当前浏览器的 IndexedDB。换浏览器、设备或网站域名不会同步；清理本站存储会删除本地记录。身份切换用于演示角色视图，不构成服务端认证或真实权限隔离。请只使用虚构文字与合成附件，不输入现实中的未成年人信息。

本站不会发送现实通知。真实试点需要独立后端、身份认证、服务端权限、监护授权、志愿者审核与人工安全流程。

## 验证

20项业务规则测试及桌面/手机20项浏览器测试已通过，覆盖完整线上与纸质闭环、退回修改、图片回传、暂停顺延、逾期、求助、刷新持久化、重置及越权地址防显示。axe辅助检查与减少动态效果检查通过；这些自动检查不能替代真实用户评估。

视觉已检查首页、四角色、长信、手机和A4打印。测试报告运行后位于 `playwright-report/index.html`。

UI方向源于项目已确认的静态参考。首页插画由内置图像工具生成，图标来自 Lucide。组件使用原生可访问控件，交互结构按项目 Skill 参考实现；没有照搬上游动效政策。
