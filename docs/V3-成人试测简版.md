# 谜语书信 V3：可选成人复测转发稿

本稿只在后续决定邀请成年人复测时使用；冻结 MVP 已完成内部四账号验证，不需要另找试用者才能发布。

试测网址：<https://riddle-letters-v3.pages.dev/>

这是一个用**虚构人物和合成书信**测试的网站。请只用私下发给你的试测账号登录，不填写真实儿童、学校、住址、联系方式或个人经历，也不要在截图里露出密码。

请两人一组同时试：**一人手机，一人电脑**。打开网址后选自己的角色并登录。每做完一步，看看另一台设备有没有出现同一封信的新状态。如果还有另一组，请错开时间；四个账号共用同一份试测数据。

1. **线上往来**：志愿者写信并提交 → 运营审核 → 小朋友读信、回信 → 运营审核 → 志愿者在首页找到并阅读回信。
2. **纸质往来**：老师预览、记录打印，再确认实际交付 → 小朋友阅读 → 老师代录合成文字回信 → 运营审核 → 老师打印、交付给志愿者 → 志愿者阅读。
3. 随手试一下页面内返回、浏览器后退、刷新，以及写信未保存时离开。做完一步后，说说你认为**现在是什么状态、下一位该由谁处理**。

如果卡住，请发回：**页面位置、点了哪个按钮、你原以为会怎样、实际怎样、截图**。也欢迎告诉我们哪一步最难找。截图前请遮住邮箱、密码等账号信息。

详细记录表可向组织者索取《V3 成人试测任务单》。
