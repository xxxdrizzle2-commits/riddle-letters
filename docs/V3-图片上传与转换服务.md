# V3 图片上传与转换服务

## 当前范围

图片服务只接入成人合成数据试测 Preview。它不创建真实账号、不启用公开图片链接，也不代表生产环境已经配置完成。现有浏览器 Demo 仍使用本地图片数据。

## 请求流程

```text
浏览器选择 PNG/JPEG
  → Pages Function 校验登录、结对关系、大小和账号配额
  → 内部 Service Binding 调用 image-transformer Worker
  → Cloudflare Images 解码、限尺寸并转为 WebP
  → Pages Function 把清理后的 WebP 写进私有 R2
  → D1 保存附件元数据与私有对象 key

浏览器读取附件
  → Pages Function 按书信权限检查当前账号
  → 从私有 R2 读取 WebP
  → 内部 Worker 按 thumbnail / letter / print 白名单转换
  → 以 private, no-store 返回图片
```

转换 Worker 不配置 `workers.dev` 地址或公开路由；Pages Function 才负责登录会话与书信权限。R2 bucket 不绑定公共域名。数据库只向客户端返回附件 ID，不返回 R2 key。

## 上传限制

- 仅 PNG、JPEG；最大 3 MiB，最多 20 MP。
- 服务端实际解码后统一转为 WebP，最大边长 2000 px；原始上传内容不写入 R2。
- 转成 WebP 会舍弃 EXIF 等图片元数据；处理后仍超过 3 MiB 的文件会被拒绝。
- 每账号最多 40 张、总容量 80 MiB；每分钟最多上传 3 张。
- 只允许孩子、志愿者上传到自己的有效伙伴关系；老师仅可为负责的纸质结对上传。运营账号不能上传。
- 已用于信件或审核版本的图片不能删除。作者可清理未被任何信件引用的附件。

## Cloudflare 资源配置

部署前由项目负责人在 Cloudflare 准备：

1. 私有 R2 bucket：`riddle-letters-v3-preview-media`，不启用公开访问。
2. Cloudflare Images 的 Workers binding，名称为 `IMAGES`。该 Images binding 需要 Images 付费订阅；调用按每月唯一图片与转换参数组合计费。
3. 部署 `media-worker/wrangler.jsonc` 中的 Worker，并在 Pages Preview 绑定它为 `IMAGE_TRANSFORMER`。
4. 将相同 R2 bucket 绑定到 Pages Preview 的 `MEDIA_BUCKET`，并保持 Preview 与未来生产环境的 bucket 隔离。

Cloudflare 官方文档确认，Pages Functions 支持 R2 与 Service Bindings；Images 字节流 binding 是 Worker 能力，能直接处理来自 R2 或请求体的图像字节，所以这里由私有 Worker 转换，不把原图公开成 URL：

- [Pages Functions bindings](https://developers.cloudflare.com/pages/functions/bindings/)
- [Images binding](https://developers.cloudflare.com/images/optimization/binding/)
- [R2 Workers API](https://developers.cloudflare.com/r2/api/workers/workers-api-reference/)

## 本地验证与上线边界

`npm test` 包含图片格式、尺寸、角色权限、配额、私有转换选项和删除限制测试；单元测试使用模拟 Images binding，不访问 Cloudflare，也不产生费用。转换 Worker 另用 Wrangler 本地低保真 Images binding 和程序生成的合成 PNG 实测了 PNG→WebP、缩略图转换及 MIME 伪装拒绝；这不会产生 Images 用量费。`npm run build:v3-preview` 检查 Pages Function 与前端类型。

当前尚未用真实 Cloudflare 账号验证 Pages→Worker Service Binding、R2 写入和 D1 元数据事务；本地 Pages 所需的 D1/R2/服务绑定资源未配置，因此不能据此声称整条云端上传链已联调。

当前代码不创建 bucket、不启用付费 Images、不部署 Worker 或 Pages。接入真实 Preview 前，需要先核实 Cloudflare 资源和预算，再在受保护的 Preview 验证上传、越权拒绝、读图、删除与跨设备状态；此次实现不能据此宣称图片服务已在线可用。
