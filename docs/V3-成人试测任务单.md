# V3 成人试测任务单

本任务单用于受保护的 V3 Preview。参与者均为成年人，所有账号、人物和信件均为合成数据。不要填写真实儿童、学校、住址、联系方式或个人经历。尚未配置受保护的远程 Preview 前，只作为本地验收记录模板，不对外分享本机服务。

## 任务

1. 从登录入口进入分配给你的成人合成账号，找到当前最需要处理的事情。
2. 以志愿者身份写一封短信，保存草稿，预览后提交审核。
3. 以运营身份找到这封待审信，逐封查看并通过；说出现在的状态和下一位处理人。
4. 以小朋友身份打开来信，回到信箱后写一封回信并提交审核。
5. 以运营身份审核回信；再以志愿者身份打开回信并继续回应。
6. 体验纸质往来：运营审核纸质信；老师打开待打印任务、预览并记录打印；再确认实际交付；查看对应的待回传任务并用合成文字代录，检查孩子核对步骤后提交审核。
7. 从信件详情使用页面内返回；再用浏览器前进、后退和刷新，确认回到的列表与筛选仍然符合预期。
8. 在写信页输入一段文字后尝试离开，检查能否选择继续写、保存后离开或放弃修改。
